# Sistema Escolar Simples

Projeto desenvolvido com JavaScript com foco em simular um sistema básico escolar.

## Funcionalidades
- Cadastro de alunos
- Organização de informações
- Estrutura de dados simples

## Tecnologias
- JavaScript
- HTML
- CSS

## Objetivo
Praticar lógica de programação e simular um sistema utilizado no ambiente escolar.

## Aprendizados
- Manipulação de dados
- Estruturação de código
- Organização de projeto
